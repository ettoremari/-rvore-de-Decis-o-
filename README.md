# Árvore de Decisão — Teste Vocacional RIASEC

Aplicação web interativa de orientação vocacional baseada no modelo RIASEC (Realista, Investigativo, Artístico, Social, Empreendedor e Convencional), desenvolvida como projeto relacionado ao curso de Ciência de Dados e Inteligência Artificial da UTFPR — Londrina.

## Como executar

Abra o arquivo `index.html` em um navegador. A aplicação é autocontida: estilos, scripts e recursos necessários estão incorporados no próprio HTML.

## Publicação com GitHub Pages

1. Acesse **Settings** deste repositório.
2. Abra **Pages** no menu lateral.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/(root)`.
5. Clique em **Save**.

Após a publicação, o GitHub exibirá o endereço público do site nesta mesma página de configurações.
